# MacEachern Research Portal

Sparse GitHub Pages portal connecting Leonard MacEachern's professional profile and the MOSAIC Group.

- Personal site: <https://maceacla.github.io/maceachern-profile/>
- Research group: <https://maceacla.github.io/mosaic-group/>

## Role in the professional workspace

This is the **main public landing-page repository** for the `maceacla.github.io` GitHub Pages domain. Its root `index.html` presents two destinations, `styles.css` defines the split portal, and `assets/` contains the two emblems and related visual files.

## Website use

- **Personal website:** the portal links to the deployed `maceachern-profile` project site.
- **Research-group website:** the portal links to the deployed `mosaic-group` project site.
- **Content ownership:** this repository should remain deliberately sparse. It should identify the two destinations and establish their relationship, but it should not duplicate biographies, research programs, student profiles, publications, or news.

The canonical content source remains `maceachern-profile-codex`. Detailed implementation belongs in the two destination repositories. Changes here affect the top-level public entry point and should therefore be tested at desktop and mobile widths before deployment.
